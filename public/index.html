💡 ¿Cómo funciona Serie n/m? Cada copia es un ejemplar de una carta. n es el número de copia que le tocó a alguien y m es el máximo de copias de esa carta (lo defines al crearla). Ejemplo: Serie 4/25 = copia 4 de 25. Cuando se agotan, esa carta ya no sale en el sorteo.

Importar cartas desde CSV

Sube un archivo CSV para crear varias cartas de golpe en una serie. Columnas: name, code, team_or_group, position_or_role, rarity, max_copies, image_url, value. La columna code es opcional: si se deja vacía, el código se genera solo. Primero verás una vista previa y luego confirmas la importación.
